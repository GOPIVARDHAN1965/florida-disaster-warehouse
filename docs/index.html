Florida Disaster Warehouse

A tested data warehouse that joins 25 years of FEMA disaster spending, NOAA hurricane tracks and Census data for Florida's 67 counties. It shows where recovery money goes, how long it takes to arrive, and whether a hurricane's track can predict which counties will get federal aid. Rebuilt every week by a scheduled pipeline.

Can a storm's track predict who gets aid?

For every storm since 2000 that passed within 300 km of a county, the model predicts whether that county will receive FEMA Individual Assistance. It uses only distance and wind near the county, plus population. It is evaluated two ways: folds split by storm (a storm is never seen in training and testing), and a time split that trains on 2000–2019 and tests on 2020–2025.

What the tests caught

  • Miami-Dade's old county code. 323 mitigation projects use FIPS 12025, Dade County's code before it was renamed Miami-Dade (12086) in 1997. A relationships test flagged them; a shared dbt macro now maps the old code everywhere.
  • Money in counties without a declaration row. The reconciliation test (county dollars must add up to FEMA's own per-disaster total) showed the disaster × county fact table was dropping dollars spent in counties that had no county-level declaration. The table's grain is now every disaster × county pair seen in any source.
  • Summary totals without project detail. Fire-management grants (e.g. the Suwannee Fire Complex, $13.8M) appear in FEMA's disaster summaries but publish no Public Assistance project rows, so they're excluded from the reconciliation check rather than silently mismatched.
  • Spelling drift. County names arrive as Miami-Dade (County), DADE, St. Johns, De Soto. A normalised county key resolves them; a custom test fails the build if a new unresolvable name shows up (tribal reservations are expected and excluded).
  • A leaky feature. The first model used each storm's lifetime peak wind and raised 56 false alarms for Tropical Storm Eta, which peaked as a Category 4 over Central America but was weak in Florida. Switching to wind measured near each county lifted held-out ROC AUC from 0.90 to 0.92.
Sources: OpenFEMA (declarations, Individual & Public Assistance, Hazard Mitigation Assistance, NFIP claims), NOAA NHC HURDAT2, U.S. Census Bureau population estimates and gazetteer. An independent project built on public data. Dollar figures are nominal (not inflation-adjusted).
